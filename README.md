# Vision Language Navigation and Manipulation with Codes
A curated collection of open-source implementations and research works at the intersection of Vision-Language Navigation (VLN) and Vision-Language Manipulation (VLM). This repository aims to gather state-of-the-art models, benchmark implementations, and practical tools that enable agents to understand visual environments, interpret natural language instructions, and perform navigation or manipulation tasks. 

Whether you're exploring embodied AI, human-robot interaction, or cross-modal understanding, this collection provides easy access to reproducible codebases, allowing researchers and developers to build upon existing work, compare approaches, and accelerate innovation in connecting computer vision, natural language processing, and physical action.

Included projects span various scenarios from indoor navigation to robotic object manipulation, with a focus on clarity, documentation, and compatibility with standard datasets and evaluation protocols. Contributions and suggestions for impactful works are always welcome.
